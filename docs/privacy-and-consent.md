## Who we are
MoneyQuest is provided by [company name], [address], [contact email]. For data questions contact [privacy email].

## What we collect (and what we never collect)
| We store | We never collect |
|---|---|
| A nickname chosen by the child (checked to block real names, emails and phone numbers) | Real names, photos, voice, email addresses, phone numbers |
| Age group (7–9, 10–12, 13–15), avatar choices, chosen city and language | Precise location, contacts, device identifiers for advertising |
| Game progress: levels, coins, badges, skills, before/after check scores, minutes played | Any payment or bank details. There are no real-money purchases |
| A 4-digit parent PIN, stored only as a salted hash | |
| If a parent adds one: a class code | |

## Why we use it
To save the child's progress, show it to the family (Parent mode) and, only if a parent adds a class code, to the class teacher (nickname and progress only). We do not use data for advertising, profiling or selling.

## Who can see it
- **The family:** everything, via Parent mode (PIN protected).
- **A teacher:** only if a parent adds the class code. They see the nickname, level, stops completed, skill levels and check scores. They never see the full game state.
- **Partner banks or schools named in an edition:** they never receive any child's data. They may receive anonymous, aggregated statistics (e.g. "average improvement 32%") only if the contract allows it and groups are large enough that no child can be identified.
- **No third-party trackers, analytics SDKs or advertising networks** are used. The app's security policy blocks them.

## Where it's stored and for how long
Progress is saved on the device and backed up to our server [hosting provider, region]. Data is kept while the family account is active and deleted [within 30 days] after a parent deletes a profile or asks us to delete the account.

## Parents' rights
Parents can see, correct and delete their child's data at any time (Parent mode → remove player, or contact [privacy email]).

## In-app consent wording (shown before the PIN is set)
> "I am this child's parent or guardian. I agree to MoneyQuest storing a nickname and game progress, as described in the privacy notice."

The grown-up must tick this box before a PIN can be set. The summary shown in the app:
1. We store only a nickname, age group, avatar choices and game progress. No real names, photos, emails or locations.
2. There are no ads, no third-party trackers and no real-money purchases.
3. Progress is saved on this device and backed up to your family account. Teachers see nicknames and progress only, and only if you add a class code.
4. Partner banks or schools never receive your child's data.
5. You can delete a child's profile and data at any time with your parent PIN.
